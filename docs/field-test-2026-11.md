# Полевой прогон на боевой ноде (13–14.11.2026)

Нода VLESS/Reality + Hysteria в Нидерландах, все клиенты приходят через relay
(у всех один IP источника), пользователь определяется по `email` из access-лога Xray.
xtg работает только как наблюдатель: без `--exec` и `--webhook`, никого не банит.
Параллельно на ноде действует правило Xray `bittorrent → BLOCK`.

Пользователи ниже обозначены буквами, адреса не приводятся.

## Пропуски

Проверено окно access-лога в 1 час (лог в tmpfs, дольше не хранится), 224 активных пользователя.
Отобраны 15 пользователей с наибольшим числом пиров на высоких портах. Ни у кого, кроме A,
нет портов 6881–6889/6969, трекеров или DHT — это мессенджеры, push (5222/5223/5228),
рекламные «трекеры» аналитики. Пропусков в этом окне не найдено.

Эвристика «много пиров на высоких портах» сама по себе торрент не отличает:
A по ней на первом месте, но следующие за ним — обычные приложения.

## Ограничения прогона

- Нет эталона: блокировки правила `bittorrent → BLOCK` в логе неотличимы от прочих BLOCK.
- Окно для сверки — 1 час, а события копятся сутки; полнота оценена только по этому часу.
- Малая выборка: 3 пользователя с торрентом в сутки. Точность и полноту в процентах
  по таким данным не считаем.
